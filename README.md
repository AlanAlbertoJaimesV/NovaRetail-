# NovaRetail-
Análisis estadístico y exploratorio del comportamiento de clientes en NovaRetail+ (2024). Mediante coeficientes de correlación (Pearson, Spearman, Punto-biserial, V de Cramér) y visualizaciones, identificamos los factores que impulsan el ingreso anual para generar recomendaciones de negocio claras y accionables.
